## 3. N33: the real public model page

**Recommended URL for the screenshot: https://www.anthropic.com/news/claude-fable-5-mythos-5** ("Claude Fable 5 and Claude Mythos 5", Anthropic, June 9, 2026).

It is the only page I found where Anthropic links all three steps in its own words:
- "as an upgrade to Claude Mythos Preview" (second paragraph, near the top)
- "It's the same underlying model as Fable 5, but with the safeguards lifted in some areas."
- "Claude Fable 5 is available everywhere today." (Availability section)

The page also notes that access to both models was suspended on June 12, 2026 and redeployed on July 1, 2026.

Alternative showing the current model: **https://www.anthropic.com/claude-fable-and-mythos-5-1** ("Introducing Claude Fable 5.1 and Claude Mythos 5.1"). Its clearest sentence is "Claude Fable 5.1 and Claude Mythos 5.1 are the same model, but with different levels of safeguards." It also says "Fable 5.1 is generally available, while Mythos 5.1 is available only through our trusted access programs." It does not mention Mythos Preview.

For a docs-style "model page", https://platform.claude.com/docs/en/models/mythos-5-1/overview has the description "Claude Mythos 5.1 is the same model as Claude Fable 5.1, available only to organizations verified through Anthropic's verification programs." The visible body says it "has the same specifications and pricing as Claude Fable 5.1". The product page https://www.anthropic.com/claude/fable says only "Mythos-level" and not "same model", so it does not support the line.
